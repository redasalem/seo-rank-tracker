# 🌟 SEO Rank Tracer - دليل الـ API الشامل

مرحباً بك في دليل المطورين الخاص بـ API مشروع **SEO Rank Tracer**. 
هذا الدليل يشرح لك كل المسارات (Endpoints) المتاحة في الباك إند، كيفية استخدامها، البيانات المطلوبة (Payloads)، وماذا تتوقع أن يرد عليك السيرفر (Responses).

---

## 🔒 المصادقة والحماية (Authentication)
معظم مسارات هذا النظام **محمية** وتحتاج إلى تسجيل دخول. عند تسجيل الدخول، ستحصل على `Token` (JWT). يجب إرسال هذا الـ Token في **Header** أي طلب محمي كالتالي:
```http
Authorization: Bearer <your_jwt_token_here>
```

---

## 🧑‍💻 1. مسارات المستخدمين (Auth API)

### 📌 أ. إنشاء حساب جديد (Register)
- **المسار:** `POST /api/auth/register`
- **الوصف:** إنشاء حساب مستخدم جديد.
- **الحماية:** ❌ غير محمي.
- **البيانات المطلوبة (Body):**
  ```json
  {
    "name": "أحمد سالم",
    "email": "ahmed@example.com",
    "password": "strongpassword123"
  }
  ```
- **الرد الناجح (201 Created):**
  يُرجع `token` وبيانات المستخدم.

### 📌 ب. تسجيل الدخول (Login)
- **المسار:** `POST /api/auth/login`
- **الوصف:** الدخول للحساب والحصول على الـ Token.
- **الحماية:** ❌ غير محمي.
- **البيانات المطلوبة (Body):**
  ```json
  {
    "email": "ahmed@example.com",
    "password": "strongpassword123"
  }
  ```
- **الرد الناجح (200 OK):**
  يُرجع `token` يمكن استخدامه في باقي المسارات.

### 📌 ج. جلب بيانات المستخدم الحالي (Get Current User)
- **المسار:** `GET /api/auth/getCurrentUser`
- **الوصف:** جلب بيانات المستخدم المسجل دخوله حالياً بناءً على الـ Token الخاص به.
- **الحماية:** ✅ محمي بالـ Token.

### 📌 د. تسجيل الخروج (Logout)
- **المسار:** `POST /api/auth/logout`
- **الوصف:** إبطال الجلسة الحالية ومسح الكوكيز (إن وجدت).

---

## 📈 2. مسارات تتبع الكلمات المفتاحية (Rank Tracking API)

### 📌 أ. إضافة كلمة مفتاحية جديدة (Add Keyword)
- **المسار:** `POST /api/rank/add`
- **الوصف:** إضافة كلمة جديدة ليتتبع السيرفر ترتيب موقعك (Domain) فيها. يقوم السيرفر بعملية بحث فورية عند الإضافة.
- **الحماية:** ✅ محمي.
- **البيانات المطلوبة (Body):**
  ```json
  {
    "keyword": "أفضل هواتف 2024",
    "url": "https://example.com/best-phones",
    "country": "EG" 
  }
  ```
  *(ملاحظة: السيرفر يقوم تلقائياً باستخراج الـ Domain من الـ URL المرفق، ولست مضطراً لإرساله).*
- **الرد الناجح (201 Created):**
  يُرجع تفاصيل الكلمة وترتيبها الحالي.

### 📌 ب. جلب جميع الكلمات (Get All Keywords)
- **المسار:** `GET /api/rank/`
- **الوصف:** جلب قائمة بجميع الكلمات المفتاحية التي يتتبعها المستخدم الحالي، مرتبة من الأحدث للأقدم.
- **الحماية:** ✅ محمي.

### 📌 ج. جلب تفاصيل كلمة واحدة (Get Keyword Details)
- **المسار:** `GET /api/rank/:id`
- **الوصف:** جلب تفاصيل كلمة معينة بـ ID الخاص بها، بما في ذلك **تاريخ ترتيبها** والمنافسين.
- **الحماية:** ✅ محمي.

### 📌 د. تحديث ترتيب الكلمة يدوياً (Refresh Keyword)
- **المسار:** `POST /api/rank/:id/refresh`
- **الوصف:** إجبار السيرفر على فتح المتصفح فوراً والبحث عن هذه الكلمة لتحديث ترتيبها الآن.
- **الحماية:** ✅ محمي.

### 📌 هـ. تفعيل/إيقاف التتبع التلقائي (Toggle Tracking)
- **المسار:** `PUT /api/rank/:id/toggle`
- **الوصف:** تشغيل أو إيقاف تحديث الكلمة تلقائياً في الخلفية بواسطة مهام السيرفر (Cron).
- **الحماية:** ✅ محمي.

### 📌 و. حذف كلمة (Delete Keyword)
- **المسار:** `DELETE /api/rank/:id`
- **الوصف:** حذف الكلمة من سجلاتك تماماً.
- **الحماية:** ✅ محمي.

## 🔍 3. مسارات تحليل السيو (SEO Analysis API)

### 📌 أ. بدء فحص موقع (Start Analysis)
- **المسار:** `POST /api/analysis/start`
- **الوصف:** إرسال رابط للسيرفر ليقوم بزيارته عبر متصفح وهمي واستخراج تفاصيل السيو (السرعة، الصور، الكلمات المفتاحية).
- **الحماية:** ✅ محمي.
- **البيانات المطلوبة (Body):**
  ```json
  {
    "url": "https://example.com/page-to-test"
  }
  ```
- **الرد الناجح (201 Created):**
  يُرجع `analysisId` يمكنك استخدامه لجلب التقرير لاحقاً.

### 📌 ب. جلب تقرير الفحص (Get Analysis Report)
- **المسار:** `GET /api/analysis/:id`
- **الوصف:** جلب التقرير المفصل للصفحة الذي يحتوي على الـ Score، الأخطاء (Issues)، والبيانات المستخرجة.
- **الحماية:** ✅ محمي.

---

## ⏰ 4. مهام الخلفية التلقائية (Cron Jobs)

### 📌 التحديث اليومي (Daily Cron)
- **المسار:** `GET /api/cron/daily`
- **الوصف:** مسار مخصص لمنصة **Vercel** فقط. تقوم المنصة بطلبه كل 15 دقيقة (أو حسب إعدادات `vercel.json`) لتحديث جميع الكلمات المفتاحية المعلقة للمستخدمين.
- **الحماية:** ✅ محمي بـ `CRON_SECRET`.
- **طريقة عمله:** لا يمكن للمستخدم العادي الدخول إليه، يجب أن يحتوي الطلب على `Authorization: Bearer <your_cron_secret>` لكي يقبل السيرفر تنفيذه.
